# 风语 · 网页试玩

由当前 Godot 项目导出，入口与 F5 相同：章节选择菜单。

## 操作

- 菜单：左右方向键选择，Enter 进入；也可点击章节。
- 2D 场景：A/D 或左右方向键移动，空格跳跃，E 互动，Q 固定，Shift 防御。
- 3D 场景：WASD 移动，Shift 加速。
- Esc 返回章节选择。

网页版采用 Compatibility 渲染，3D 光照、雾效可能与桌面 Forward Plus 有差异。
首次打开需要下载游戏资源，请使用支持 WebGL 2 的现代桌面浏览器。
